# 六爻卜卦系統 — Vue 3 版本

本專案由使用者 2026-10-16 提供的原版 HTML/CSS/JS 轉換，使用 Vite 開發環境。

## 執行

需先安裝 Node.js（建議 Node 20.19+ 或 Node 22.12+）。在此資料夾執行：

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的本機網址（通常 http://localhost:5173）。

## 建置與資料測試

```bash
npm run build
npm run test:logic
```

## 專案檔案

- `src/App.vue`：畫面與互動；修改輸入框、龜殼、結果摘要等。
- `src/divination.js`：三枚銅錢、變爻、64 卦資料及運算；兩版計算邏輯一致。
- `src/style.css`：保留原始網頁的 CSS 外觀。
- `public/image/`：龜殼與 8 組硬幣圖片；畫面依 Vite 的 `BASE_URL` 組合資源路徑，支援專案子路徑部署。

## 行為

1. 第一爻時鎖定問題。
2. 每次點擊龜殼播放 850 毫秒搖動效果，並產生一爻。
3. 六爻記錄為初爻至上爻；展示時上爻在上。
4. 6 老陰變陽、9 老陽變陰；以六位字串比對本卦與變卦。
5. 六爻結束才顯示結果；重新起卦會清空資料，並取消尚未結束的動畫計時器。
